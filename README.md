## 📋 เกี่ยวกับโปรเจค

เว็บไซต์ Portfolio ส่วนตัวแบบ Single Page Application (SPA) ที่ออกแบบมาเพื่อแสดงผลงาน ประวัติ และกิจกรรมต่างๆ ด้วยดีไซน์ที่ทันสมัยและ Dynamic พร้อมกับ Animation ที่สวยงาม

## ✨ คุณสมบัติ (Features)

- 🎨 **ดีไซน์สวยงาม** — ใช้สี Crimson Red, Golden Yellow และ Dark Brown ตามต้นฉบับ
- 📱 **Responsive Design** — รองรับทุกขนาดหน้าจอ (Desktop, Tablet, Mobile)
- ⚡ **Dynamic Animations** — มี scroll animation, parallax, typing effect, gear rotation
- 🖼️ **Lightbox Gallery** — คลิกดูรูปใบประกาศนียบัตร (Certificate) แบบขยาย
- 🔝 **Smooth Scrolling** — เลื่อนหน้าจออย่างลื่นไหล
- 🧭 **Active Navigation** — เมนูจะ highlight ตาม section ที่กำลังดูอยู่
- 🎯 **Intersection Observer** — แสดง animation เมื่อ element เข้ามาใน viewport
- 🌐 **Font Awesome Icons** — ใช้ไอคอนจาก Font Awesome 6
- 🔤 **Google Fonts** — ใช้ฟอนต์ Kanit & Prompt (ภาษาไทย)

## 🚀 วิธีใช้งาน

### เปิดดูบนเครื่อง (Local)
1. ดาวน์โหลดหรือ Clone โปรเจคนี้
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

### Deploy บน GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ `Port/`
3. ไปที่ **Settings** > **Pages**
4. เลือก Branch: `main` และ Folder: `/ (root)`
5. กด **Save** แล้วรอสักครู่ เว็บไซต์จะพร้อมใช้งาน
